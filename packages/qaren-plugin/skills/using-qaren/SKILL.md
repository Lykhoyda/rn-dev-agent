# Using QaReN

Read the [CLI guide](https://github.com/Lykhoyda/rn-dev-agent/blob/develop/packages/qaren-cli/README.md) before operating QaReN. It owns commands,
configuration, evidence, privacy, and resource ownership for this checkout.

```text
Requested work
├── Runtime setup       -> CLI guide: Build / Plugin runtime installation
├── Working-tree QA     -> CLI guide: Check a plan
├── Pull-request QA     -> CLI guide: Test a pull request
├── Saved-block replay  -> CLI guide: Saved blocks
├── Retained run        -> CLI guide: iOS admission and cleanup
└── Product feedback    -> sending-feedback skill
```

Follow the selected section through its receipt and evidence readback. Report the
observed verdict and unexecuted coverage separately; installation or a successful
build alone does not establish a passing app journey.
