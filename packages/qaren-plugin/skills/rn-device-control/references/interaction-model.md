# QaReN interactions

The supported plan interaction contract is owned by
[Check a plan](https://github.com/Lykhoyda/rn-dev-agent/blob/develop/packages/qaren-cli/README.md#check-a-plan), including target resolution,
occlusion recovery, fill verification, and keyboard fallback.
For stored identities and replay limits, read [Saved blocks](https://github.com/Lykhoyda/rn-dev-agent/blob/develop/packages/qaren-cli/README.md#saved-blocks).
The separate compiler and library-interpreter domain contract is owned by the
[replay dialect](https://github.com/Lykhoyda/rn-dev-agent/blob/develop/apps/docs-site/src/content/docs/actions/rn-flow-1.md).
