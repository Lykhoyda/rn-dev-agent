# App build preparation

QaReN's supported iOS build routes and native-dependency preparation limits are
owned by [CLI-owned iOS build routes](https://github.com/Lykhoyda/rn-dev-agent/blob/develop/packages/qaren-cli/README.md#cli-owned-ios-build-routes).
For scenario-based preparation, read [Preparation verbs](https://github.com/Lykhoyda/rn-dev-agent/blob/develop/packages/qaren-cli/README.md#preparation-verbs)
and [Scenarios](https://github.com/Lykhoyda/rn-dev-agent/blob/develop/packages/qaren-cli/README.md#scenarios).

The former EAS artifact resolver and ensure-running scripts are absent from
this plugin. These preparation contracts do not provide an EAS artifact-install workflow.
