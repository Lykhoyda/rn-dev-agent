---
title: "device_accept_system_dialog"
description: "Tap an OS-level accept button on the exact session device"
---

Tap an OS-level accept button on the exact session device. iOS prefers the capability-bound native runner so SpringBoard-owned dialogs are reachable; DIALOG_BUTTON_NOT_FOUND returns availableButtons for an exact-label retry.

## Parameters

| Name | Type | Required | Default | Constraints | Description |
|------|------|----------|---------|-------------|-------------|
| `label` | `unknown` | No |  |  |  |
| `platform` | `unknown` | No |  |  | Authority-bound platform; conflicting values are refused |
| `timeoutMs` | `unknown` | No |  | min: 1000, max: 120000, integer |  |

## Usage

```
device_accept_system_dialog()
```
